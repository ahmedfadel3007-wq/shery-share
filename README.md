# 🌩️ Shery Share

برنامج تخزين ونقل ملفات شخصي متعدد المستخدمين — تقدر تبعت وتستقبل منه صور/فيديوهات/أغاني/أي ملفات لأي حد مسجل معاك على نفس السيرفر، ومثبّت كتطبيق (PWA) بأيقونة Shery على شاشتك.

## المميزات
- تسجيل حسابات متعددة (كل واحد باسمه وباسوورده)
- رفع / تنزيل (حفظ) / حذف ملفات، وإنشاء مجلدات
- تصنيف تلقائي للملفات: 🖼️ صور / 🎬 فيديوهات / 🎵 أغاني / 📄 ملفات وبرامج
- شريط جانبي (☰) بيوضح مساحة التخزين المستخدمة مقسّمة بالألوان حسب النوع، ومساحة القرص المتبقية على الجهاز
- إرسال/مشاركة ملف لمستخدم تاني مسجل في نفس السيرفر (يظهر عنده في "📥 الوارد")
- إعادة توجيه أي ملف لأي تطبيق تاني (AirDrop/بلوتوث/واتساب...) عن طريق قائمة المشاركة الأصلية بتاعة نظام جهازك
- PWA: يتثبت على الشاشة الرئيسية بأيقونة Shery الحقيقية، ويتحدث تلقائيًا كل ما تفتحه

## التشغيل (خطوة بخطوة)

### 1. تثبيت المكتبات (مرة واحدة فقط)
افتح Terminal داخل مجلد المشروع (في VS Code: Terminal > New Terminal) واكتب:
```
npm install
```

### 2. تشغيل السيرفر
```
npm start
```
لو كل حاجة تمام، هتشوف رسالة شبيهة بده:
```
🌩️  Shery Share شغالة على البورت 8080
```

### 3. الدخول من جهازك وتثبيت التطبيق
افتح المتصفح على:
```
http://localhost:8080
```
اعمل حساب من "سجّل دلوقتي"، وابدأ تستخدم Shery Share.

**لتثبيته كتطبيق بأيقونة على الشاشة:**
- على أندرويد/كروم: هيظهرلك اختيار "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية" من قائمة المتصفح (⋮)
- على آيفون/سفاري: دوس على زرار المشاركة (⬆️) ثم "إضافة إلى الشاشة الرئيسية"
- على ويندوز/كروم: هيظهر أيقونة تثبيت (⊕ أو شاشة بسهم) في شريط العنوان

### 4. الدخول من جهاز تاني على نفس الشبكة (أوفلاين، بدون إنترنت)
1. اعرف الـ IP المحلي لجهازك:
   - ويندوز: `ipconfig` وشوف "IPv4 Address"
   - ماك/لينكس: `ifconfig` أو `ip addr`
2. من الجهاز التاني (لازم يكون على نفس شبكة الواي فاي) افتح:
```
http://<الـ-IP-بتاع-جهازك>:8080
```

### 5. الدخول من الإنترنت (أونلاين، من أي مكان في الدنيا)
أسهل طريقة بدون أي إعدادات روتر، باستخدام أداة اسمها **ngrok**:
1. نزّل ngrok من https://ngrok.com/download وسجّل حساب مجاني
2. شغّل السيرفر بتاعك (`npm start`)
3. في Terminal تاني اكتب:
```
ngrok http 8080
```
4. هيعطيك رابط شبيه بـ `https://xxxx.ngrok-free.app` — ده الرابط اللي أي حد في أي مكان يفتحه ويدخل بيه.

> ملاحظة: الرابط ده بيتغيّر كل مرة تشغّل ngrok من جديد (في النسخة المجانية).

## إعادة التوجيه لـ AirDrop/بلوتوث/واتساب
لما تدوس زرار "↗️" جنب أي ملف، هتفتح قائمة المشاركة الأصلية بتاعة نظام جهازك (نفس القائمة اللي بتظهر لما تدوس Share في أي تطبيق)، وفيها AirDrop (لو آيفون/ماك) أو Nearby Share (لو أندرويد) أو أي تطبيق تواصل زي واتساب. البرنامج مش بيعمل البروتوكول ده بنفسه، لكنه بيسلّم الملف لنظام جهازك يختار بيه.

## الأمان
- غيّر المفتاح السري قبل ما تنشر السيرفر على الإنترنت:
```
CLOUD_SECRET_KEY=اكتب-نص-عشوائي-طويل-هنا
```
- استخدم باسوردات قوية لحسابات المستخدمين.
- ngrok بيوفر HTTPS أوتوماتيك، فده كافي للاستخدام الشخصي.
